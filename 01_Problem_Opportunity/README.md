# Problem & Opportunity

**Problem:** In enclosed utility spaces, gas leakage or developing fire may go unnoticed. This project explores an educational low-voltage prototype combining gas/smoke sensing, flame indication, local alarm logic and ventilation control.

**Users:** ECE students, embedded-systems demonstrators and technical reviewers.

**Outcome:** A bench-validated demonstrator with sensor acquisition, explicit operating states, local indication and a low-voltage fan output.

**Boundaries:** Not certified, not for real-life protection, no LPG release/open-flame tests, no mains switching or gas-valve control.

**Questions to resolve:** Exact module revisions, sensor AO/DO voltages, fan startup current, relay 3.3 V compatibility.
